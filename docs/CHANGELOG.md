# 更新日志

## 语义化版本控制

版本号信息遵循 `X.Y.Z` 格式：

- **X（主版本号）**：当进行不兼容的 API 变更、架构重构或核心功能颠覆性更新时递增。
- **Y（次版本号）**：当新增向后兼容的功能（如新增特性、模块）时递增。
- **Z（修订号）**：当进行向后兼容的问题修复、小优化或依赖更新时递增。

预发布版本：在修订号后加入 `-alpha` 表示该版本为测试版，稳定性有待验证。
